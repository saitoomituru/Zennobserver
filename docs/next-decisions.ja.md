# 次段階で決める項目（未採用）

この一覧は運用ルールを制定するものではありません。初期基盤を構築した停止位置の記録です。

2026-10-03追記: 記事・Bookの編集単位は[編集メタルール](editorial-rules.ja.md)に合意を記録しました。
以下は引き続き、自動処理と公開運用について決める項目です。

| 項目 | 決める内容 | 現在 |
|---|---|---|
| 収集対象 | 継続的な収集対象・ファイル・公開範囲 | 公開リポを固定配置済み。自動取得条件は未決定 |
| 更新 | 週次の曜日・時刻・タイムゾーン・追従ブランチ | scheduler・自動追従なし |
| 分類 | 既存記事との対応、記事追加・分割、分類不能の基準 | 自動分類なし |
| 生成 | 変換規則、MDX対応、生成器、エージェント実行環境・費用 | 変換・生成なし |
| 来歴 | 元ファイル・commit・実験条件・著者・licenseの記録形式 | 記事テンプレートに記録欄のみ |
| Issue | 未分類差分の本文・重複防止・再処理条件 | 自動起票なし |
| 公開 | 記事更新の権限、検証と同期の順序、対象ブランチ | Zenn公式連携の接続手順のみ |
| 復旧 | 不成功・資料欠損・生成差分競合・同期失敗の扱い | 自動復旧なし |

既存toolの参照先は、Manifestの`docs/operations/`、Atlantisの`atlantis_cli/`、
`scripts/`、`.github/workflows/`、`magi/0.2.1/`です。
運用を実装する際は対象toolの入出力・副作用・revision・実行環境を読んでから再利用を決めます。
