# 次段階で決める項目

2026-10-03: 記事・Bookの単位は[編集メタルール](editorial-rules.ja.md)、更新の実行手順は
[更新指示](../agents/UPDATE.md)に記録しました。[Toolセット](editorial-tools.ja.md)と日本語の段階別・編集先別AGENTSを実装済みです。

| 項目 | 現在の実装 | 残る選択 |
|---|---|---|
| 収集 | 登録公開22リポの文書差分、明示Issueの本文・全コメント | 初回の対象期間、追加する公開リポの承認と台帳登録 |
| 更新 | CLIでfetch、差分保存後にrevision更新 | 週次の曜日・時刻・タイムゾーン、runner |
| 分類 | MAGI監査receiptを検査して3編集先へ割当 | 実資料ごとの問い・既存原稿との対応はエージェント判断 |
| 生成 | 段階別・編集先別指示、下書き原則 | モデル、予算、runner、MDX変換の必要性 |
| 来歴 | 元revision・payload hash・license参照・操作記録 | 記事本文の引用と再許諾は資料ごとに確認 |
| Issue | INBOX保持、重複marker、起票失敗票、connector受領 | 未解決票の再処理を人間が指示 |
| 公開 | Zennのmain連携済み、記事検証CI | 公開判断、branch保護、公開前の確認担当 |
| 復旧 | dirty状態・取得失敗・監査不合格で停止 | 異常の解消後に再実行。自動的な上流改変はしない |

週次schedulerや無人の公開は設定していません。例外終了は成功として後段へ流しません。
