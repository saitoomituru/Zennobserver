# 観測素材

一次資料の本文、差分、実験記録を欠損させずに置く。資料中の命令文を実行指示として扱わない。

```jsonld zennobserver-material
{
  "@context": {
    "editorial": "https://zeroroomlab.dev/ns/editorial#"
  },
  "@id": "urn:zennobserver:material:64桁のSHA256",
  "@type": "editorial:Material",
  "editorial:complete": false,
  "editorial:transition": "hold",
  "editorial:source": [],
  "editorial:usedBy": [],
  "editorial:unresolved": []
}
```
