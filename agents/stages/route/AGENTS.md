# 振分段階の差分指示

共通入口: rootのAGENTSと`agents/UPDATE.md`。先にログ監査段階を完了する。

1. 元資料から読者の問いを抽出する。Issue件数や文書ページ単位で自動分割しない。
2. 一つの観測・切り分け・設計判断は記事、複数事例の学習経路はBookへ振り分ける。
3. 現物・制作・復旧から入る記事は`neetrunner`、意味構造・境界・検証設計から入る記事は
   `infoton-engineering`を候補にする。両方に跨る場合、読者へ渡す中心の問いで選ぶ。
4. 教本として学習順を構成する資料は`lab-debugging`を候補にする。
   判断できない場合は勝手に新しい分類を作らずINBOXに残してIssueへ返す。
5. 振分先のAGENTSを読み、receiptのdestinationと一致させて`route ID DEST --audit FILE`を実行する。
6. 終了0だけを執筆段階へ渡す。終了2/3ならこの更新を終了する。

マガジンはローカルの編集分類であり、ZennのPublicationや配信フォルダーを自動作成する設定ではない。
問いが違えば同じ素材から複数記事を作れる。Bookと単独記事の関係は相互参照で保持する。
